# Apex OS

Apex OS is a lightweight, custom-built operating system designed for x86 architecture. This is the very first version, expect a lot of bugs.

## Features
- Custom bootloader and protected mode setup.
- Preemptive task scheduler.
- PS/2 keyboard and mouse drivers.
- PCI Wi-Fi hardware detection.
- Text-mode GUI and interactive shell.
- Simple file system implementation.
